# 심이베 캘린더 화면 설계서 (v1.0)

| 항목 | 내용 |
|---|---|
| 대상 버전 | 1.0 (안드로이드) |
| 와이어프레임 | [Figma: 심이베 캘린더 화면 설계서](https://www.figma.com/design/Xc9iKP4iYwC2uMG3LOOxMz) |
| 참고 문서 | `docs/02-requirements/요구사항정의서.md`, `docs/03-design/화면목록및흐름도.md` |

와이어프레임은 배치만 보여주는 회색조 설계도이며, 색상·글꼴·아이콘 같은 시각 디자인은 다음 단계에서 정한다. 분류 색상만 구분을 위해 실제 색으로 표시했다.

## 1. 공통 규칙

| 항목 | 규칙 |
|---|---|
| 화면 크기 | 360 × 760 (안드로이드 기준 폭 360dp) |
| 글꼴 | Noto Sans KR (와이어프레임 기준) |
| 하단 탭 | 달력(달력 아이콘) / 검색(돋보기) / 연결(사슬 링크) / 알림(편지 봉투) / 설정(톱니바퀴). 알림 탭에 안 읽은 개수 배지 |
| 상단 바 | 왼쪽에 뒤로 가기(←) 또는 닫기(✕)와 화면 제목, 오른쪽에 주요 동작(저장, 수정, 완료 등) |
| 바텀시트 | 뒤쪽 화면을 어둡게 처리하고 아래에서 올라온다. 아래로 내리거나 바깥을 누르면 닫힌다 |
| 확인 팝업 | 되돌릴 수 없거나 영향이 큰 동작(빼기, 해제, 삭제, 로그아웃)은 팝업으로 한 번 더 확인한다. 위험한 동작 버튼은 빨간색 |
| 오프라인 | 화면 위쪽에 "오프라인 상태" 안내를 띄우고 등록·수정 버튼을 비활성화한다 (NFR-004) |

## 2. 설계 단계에서 새로 정한 사항

요구사항 정의서에 없던 내용을 화면 설계 과정에서 정했다.

| 항목 | 결정 | 관련 화면 |
|---|---|---|
| 달력 날짜 칸 표시 | 하루 일정은 분류 색 점(최대 3개, 더 있으면 "+"), 여러 날 일정은 기간 전체를 잇는 분류 색 선 | SCR-010 |
| 개인 항목 변경 위치 | 분류와 미리 알림은 일정 상세에서 바로 바꾼다 | SCR-012 |
| 저장 버튼 위치 | 일정 등록·수정 화면 상단 오른쪽 | SCR-013 |
| 새 일정의 기본 분류 | "개인" | SCR-013 |
| 날짜별 목록 정렬 | 하루 종일 일정 먼저, 그다음 시간순. 마감형은 종료 시간 기준 | SCR-011 |
| 알림 목록 범위 | 공유받음, 수정, 연결 알림만 쌓는다. 미리 알림은 휴대폰 알림으로만 온다 | SCR-040 |
| 분류 순서 | 만든 순서, "그 외"는 항상 맨 아래 | SCR-052 |
| 인증 메일 재발송 | 다시 보내려면 60초를 기다려야 한다 | SCR-004 |
| 비밀번호 찾기 안내 | 가입하지 않은 이메일이어도 같은 안내를 보여 가입 여부를 노출하지 않는다 | SCR-005 |
| 회원 탈퇴 확인 | 현재 비밀번호 재입력과 안내 확인 체크가 있어야 탈퇴할 수 있다 | SCR-054 |
| 혼자 남은 일정 빼기 | 참여자가 나뿐이면 팝업 제목을 "일정을 삭제할까요?"로 바꾼다 | POP-001 |

## 3. 화면별 설계

### 3.1 시작과 인증

#### SCR-001 시작
1. 앱 로고와 앱 이름을 가운데 표시한다.
2. 로그인 상태를 확인해 로그인되어 있으면 달력(SCR-010), 아니면 로그인(SCR-002)으로 이동한다. (REQ-AUTH-005)

#### SCR-002 로그인
1. 이메일과 비밀번호 입력란
2. 로그인 실패 시 빨간 글씨로 오류 안내. 이메일 인증을 하지 않은 계정은 이메일 인증 안내(SCR-004)로 이동
3. 로그인 버튼: 성공하면 달력(SCR-010)으로 이동, 로그인 상태 유지 (REQ-AUTH-005)
4. 회원가입(SCR-003), 비밀번호 찾기(SCR-005) 링크

#### SCR-003 회원가입
1. 이메일: 로그인용, 다른 사용자에게 공개되지 않는다는 안내 (REQ-AUTH-001, NFR-007)
2. 비밀번호와 비밀번호 확인: 8자 이상, 영문과 숫자 포함. 조건에 맞지 않거나 두 값이 다르면 입력란 아래 안내 (NFR-005)
3. 고유 아이디: 규칙 검사와 중복 확인 버튼, 가입 후 변경 불가 안내 (REQ-AUTH-003, 004)
4. 이름: 다른 사람에게 보이는 표시 이름
5. 가입하기: 모든 항목이 올바르고 중복 확인을 통과해야 활성화. 가입 후 이메일 인증 안내(SCR-004)로 이동

#### SCR-004 이메일 인증 안내
1. 가입한 이메일 주소와 인증 링크 안내 (REQ-AUTH-002)
2. 로그인하러 가기: 로그인(SCR-002)으로 이동
3. 인증 메일 다시 보내기: 누르면 "다시 보냈어요" 안내, 60초 대기 후 다시 누를 수 있음

#### SCR-005 비밀번호 찾기
1. 안내 문구와 이메일 입력란 (REQ-AUTH-007)
2. 재설정 메일 보내기: 보낸 뒤 "메일을 보냈어요" 안내. 가입하지 않은 이메일이어도 같은 안내를 보여준다

#### SCR-006 새 비밀번호 설정
1. 메일의 재설정 링크를 누르면 앱에서 열린다(딥링크) (REQ-AUTH-007)
2. 새 비밀번호와 확인: 비밀번호 규칙 적용 (NFR-005)
3. 비밀번호 변경: 완료되면 로그인(SCR-002)으로 이동

### 3.2 달력 탭

#### SCR-010 달력
1. 월 이동: ‹ › 버튼 또는 좌우로 밀어서 이전·다음 달로 이동 (REQ-VIEW-001)
2. 오늘: 누르면 오늘이 있는 달로 돌아온다 (REQ-VIEW-003)
3. 분류 칩: 누르면 켜고 끈다. 꺼진 분류의 일정은 달력과 날짜별 목록에서 숨긴다. 칩이 많으면 가로로 밀어서 본다 (REQ-CAT-007)
4. 날짜 칸: 하루 안에 끝나는 일정은 날짜 숫자 아래에 분류 색 점으로 표시. 최대 3개, 더 있으면 "+". 여러 날에 걸친 일정은 점 대신 시작일부터 종료일까지 분류 색 선으로 잇는다. 주가 바뀌면 다음 줄에서 이어 그리고, 선의 둥근 끝은 실제 시작일과 종료일에만 둔다. 선은 점보다 위에 그린다 (REQ-TIME-004)
5. 날짜를 누르면 날짜별 일정 목록(SCR-011)이 올라온다 (REQ-VIEW-002)
6. + 버튼: 일정 등록(SCR-013). 오프라인이면 비활성화 (NFR-004)
7. 하단 탭과 알림 배지 (REQ-NOTI-011)

#### SCR-011 날짜별 일정 목록 (바텀시트)
1. 선택한 날짜와 요일 (REQ-VIEW-002)
2. + 이 날짜로 추가: 날짜가 미리 채워진 일정 등록(SCR-013)으로 이동
3. 일정 항목: 분류 색 막대, 제목, 시간. 누르면 일정 상세(SCR-012)
4. 정렬: 하루 종일 일정 먼저, 그다음 시간순. 마감형은 종료 시간 기준
5. 마감형 일정은 제목 앞에 "마감" 표시, 시간은 "~까지"로 표기 (REQ-TIME-007)
6. 공유 일정은 오른쪽에 참여자 수 표시
7. 분류 필터에서 꺼진 분류의 일정은 보이지 않는다

#### SCR-012 일정 상세
1. 공통 항목: 제목, 시간, 반복 정보 (REQ-EVENT-009)
2. 수정: 일정 수정(SCR-013)으로 이동. 참여자 누구나 가능 (REQ-EVENT-006)
3. 나에게만 적용되는 설정: 분류와 미리 알림을 이 화면에서 바로 바꾼다. 다른 참여자에게는 영향 없음 (REQ-SHARE-005, REQ-NOTI-001)
4. 장소, 메모: 입력한 경우에만 표시
5. 참여자 목록: 이름과 고유 아이디, 본인은 "나" 표시. 다른 참여자를 뺄 수는 없다 (REQ-SHARE-004)
6. 내 달력에서 빼기: 확인 팝업(POP-001) 후 나만 빠진다 (REQ-EVENT-007)
7. 다른 참여자가 수정하면 화면이 바로 갱신된다 (REQ-SHARE-006)

#### SCR-013 일정 등록·수정
1. 상단: ✕는 닫기(입력 내용이 있으면 "작성을 취소할까요?" 확인), 저장은 오른쪽 위. 수정할 때는 제목이 "일정 수정" (REQ-EVENT-001, 006)
2. 제목: 필수, 최대 100자. 비어 있으면 저장 불가 (REQ-EVENT-003)
3. 하루 종일: 켜면 시간 칸이 사라지고 시작·종료 날짜만 남는다 (REQ-TIME-002)
4. 시작·종료: 날짜와 시간(5분 단위)을 따로 고른다. 시간은 ✕로 비울 수 있다. 둘 다 비면 저장 불가, 기간형은 종료가 시작보다 늦어야 한다 (REQ-TIME-003~006)
5. 분류: 내 분류 목록에서 하나 선택(필수). 기본값은 "개인" (REQ-CAT-002)
6. 공유할 사람: 공유할 사람 선택(SCR-014)으로 이동 (REQ-SHARE-001, 003)
7. 반복: 반복 설정(SCR-015) 바텀시트 (REQ-REPEAT-001~003)
8. 미리 알림: 시간 일정은 없음 / 30분 전 / 1일 전, 하루 종일 일정은 없음 / 당일 오전 9시. 기본값 없음 (REQ-NOTI-001~004)
9. 장소(최대 100자), 메모(최대 1,000자) (REQ-EVENT-004, 005)

#### SCR-014 공유할 사람 선택
1. 안내 문구: 연결된 사람만 고를 수 있고 참여자는 뺄 수 없음 (REQ-SHARE-001, 004)
2. 목록: 내 연결 목록(이름, 고유 아이디). 여러 명 선택 가능
3. 이미 참여 중인 사람: 회색 체크로 고정, 선택 해제 불가, "참여 중" 표시
4. 나와 연결되지 않은 참여자(다른 사람이 추가한 사람)는 이 목록에 나오지 않고 일정 상세의 참여자 목록에서만 보인다
5. 완료: 선택을 일정 등록·수정(SCR-013)에 반영. 저장하면 새 참여자 달력에 승인 없이 바로 등록된다 (REQ-SHARE-002, 003)
6. 연결된 사람이 없으면 "아직 연결된 사람이 없어요"와 연결 탭 바로가기 표시

#### SCR-015 반복 설정 (바텀시트)
1. 반복 종류: 반복 안 함, 매주(일정 날짜의 요일), 매주 여러 요일, 매월 같은 날짜, 매년 같은 날짜. 보기 문구는 일정 날짜에 따라 바뀐다 (REQ-REPEAT-001)
2. 매주 여러 요일: 요일 버튼을 여러 개 고른다. 최소 1개
3. 반복 종료: 반복을 고르면 필수. 비어 있으면 적용 불가, 일정 시작 날짜 이후여야 한다 (REQ-REPEAT-002)
4. 매월 29~31일을 고르면 "해당 날짜가 없는 달은 마지막 날에 표시돼요" 안내 (REQ-REPEAT-003)
5. 적용: 일정 등록·수정(SCR-013)의 반복 칸에 반영. 반복 일정의 수정은 전체에 적용된다 (REQ-REPEAT-004)

#### POP-001 내 달력에서 빼기 확인
1. 일정 상세(SCR-012)의 "내 달력에서 빼기"를 누르면 뜬다 (REQ-EVENT-007)
2. 안내 문구: 나만 빠지고 다른 참여자는 유지, 반복 일정은 전체가 빠짐 (REQ-REPEAT-004)
3. 빼기: 달력(SCR-010)으로 돌아간다. 내가 마지막 참여자면 일정이 서버에서 삭제된다 (REQ-EVENT-008)
4. 참여자가 나뿐인 일정은 제목을 "일정을 삭제할까요?"로 바꾼다

### 3.3 검색 탭

#### SCR-020 일정 검색
1. 검색창: 입력하면 일정의 제목, 장소, 메모에서 찾는다 (REQ-SEARCH-001)
2. 검색 범위: 내가 참여 중인 일정 전체. 달력의 분류 필터와 상관없이 모든 분류를 검색 (REQ-SEARCH-002)
3. 결과 항목: 날짜, 분류 색, 제목, 시간과 검색어가 들어간 항목(장소·메모). 누르면 일정 상세(SCR-012)
4. 정렬: 가까운 날짜 순. 반복 일정은 가장 가까운 날짜 하나로 묶고 "반복" 표시 (REQ-SEARCH-003)
5. 검색어가 없으면 "제목, 장소, 메모로 일정을 찾아보세요", 결과가 없으면 "검색 결과가 없어요" 안내

### 3.4 연결 탭

#### SCR-030 연결
1. 상단 전환: 연결된 사람 / 받은 요청 / 보낸 요청, 각각 개수 표시 (REQ-CONN-005)
2. + 사용자 찾기: 사용자 찾기(SCR-031)로 이동
3. 연결된 사람: 이름과 고유 아이디. ⋮ 메뉴에서 연결 해제 → 확인 팝업(POP-002) (REQ-CONN-006)
4. 받은 요청: 수락하면 연결된 사람으로 옮겨지고, 거절하면 목록에서 사라진다. 거절은 상대에게 알리지 않는다 (REQ-CONN-003)
5. 보낸 요청: 각 항목에 "요청 취소" 버튼 (REQ-CONN-004)
6. 연결 알림을 누르면 해당 탭이 선택된 상태로 열린다 (요청 받음 → 받은 요청, 수락됨 → 연결된 사람)
7. 목록이 비면 "아직 연결된 사람이 없어요. 고유 아이디로 친구를 찾아보세요" 안내

#### SCR-031 사용자 찾기
1. 검색: 고유 아이디를 정확히 입력해야 찾는다(부분 검색 없음) (REQ-CONN-001)
2. 결과: 이름과 고유 아이디만 표시, 이메일은 보이지 않는다 (NFR-007)
3. 연결 요청: 누르면 "요청함"으로 바뀌고 보낸 요청에 추가된다. 이미 연결됐으면 "연결된 사람", 대기 중이면 "요청함"으로 비활성화. 상대가 나에게 먼저 요청했다면 "요청 수락" (REQ-CONN-002)
4. 없는 아이디는 "해당 아이디의 사용자가 없어요", 내 아이디는 "내 아이디예요" 안내

#### POP-002 연결 해제 확인
1. 연결(SCR-030)의 ⋮ 메뉴에서 "연결 해제"를 누르면 뜬다 (REQ-CONN-006)
2. 안내 문구: 함께 참여 중인 일정 유지, 앞으로의 공유만 막힘, 상대에게 알리지 않음
3. 해제: 연결된 사람 목록에서 사라진다

### 3.5 알림 탭

#### SCR-040 알림 목록
1. 목록: 최신순. 공유받음, 수정, 연결 요청·수락 알림을 모아 보여준다 (REQ-NOTI-009)
2. 미리 알림(일정 30분 전 등)은 휴대폰 알림으로만 오고 이 목록에는 쌓이지 않는다
3. 안 읽은 알림: 회색 배경과 빨간 점으로 강조. 하단 알림 탭에 개수 배지 (REQ-NOTI-011)
4. 모두 읽음: 모든 알림을 읽음으로 바꾼다. 알림을 누르면 그 알림만 읽음 처리
5. 알림을 누르면 일정 알림은 일정 상세(SCR-012), 연결 알림은 연결(SCR-030)로 이동. 빠진 일정이면 "더 이상 참여하지 않는 일정입니다" 안내 (REQ-NOTI-010)
6. 90일이 지난 알림은 자동 삭제 (REQ-NOTI-012). 알림이 없으면 "아직 받은 알림이 없어요"

### 3.6 설정 탭

#### SCR-050 설정
1. 내 정보: 이름, 고유 아이디, 이메일(본인에게만 표시)
2. 프로필 수정: SCR-051로 이동 (REQ-AUTH-008)
3. 분류 관리: 분류 개수 표시, SCR-052로 이동
4. 로그아웃: 확인 팝업(POP-004) (REQ-AUTH-006)
5. 회원 탈퇴: 빨간 글씨, SCR-054로 이동 (REQ-AUTH-009)
6. 앱 버전 표시

#### SCR-051 프로필 수정
1. 이름: 수정 가능, 1~20자, 중복 허용 (REQ-AUTH-008)
2. 고유 아이디, 이메일: 회색 읽기 전용 (REQ-AUTH-008)
3. 저장: 이름이 바뀌었을 때만 활성화. 저장하면 설정(SCR-050)으로 돌아간다

#### SCR-052 분류 관리
1. 분류 목록: 색상과 이름. 가입 시 기본 5개(공유받은 일정, 개인, 직장, 가족, 그 외)가 만들어진다 (REQ-CAT-001)
2. 순서: 만든 순서, "그 외"는 항상 맨 아래
3. 항목을 누르면 분류 수정(SCR-053), + 추가는 빈 분류 추가(SCR-053) (REQ-CAT-003)
4. "그 외"는 삭제 불가 표시. 이름과 색상은 바꿀 수 있다 (REQ-CAT-006)
5. "공유받은 일정"을 삭제하면 이후 공유받는 일정은 "그 외"로 들어온다 (REQ-SHARE-005)

#### SCR-053 분류 추가·수정
1. 상단 제목: 추가할 때는 "분류 추가", 수정할 때는 "분류 수정" (REQ-CAT-003)
2. 이름: 필수, 내 분류끼리 중복 불가 (REQ-CAT-003)
3. 색상: 정해진 12색 중 하나 선택, 선택한 색은 테두리와 체크 표시 (REQ-CAT-004)
4. 분류 삭제: 수정할 때만 보이고, "그 외"에서는 숨긴다. 누르면 확인 팝업(POP-003) (REQ-CAT-005, 006)

#### POP-003 분류 삭제 확인
1. 분류 수정(SCR-053)의 "분류 삭제"를 누르면 뜬다
2. 안내 문구: 이 분류에 속한 일정 개수와 "그 외"로 옮겨진다는 내용 (REQ-CAT-005)
3. 삭제: 분류 관리(SCR-052)로 돌아간다

#### POP-004 로그아웃 확인
1. 설정(SCR-050)의 "로그아웃"을 누르면 뜬다
2. 로그아웃: 이 기기의 알림 수신을 끄고 로그인(SCR-002)으로 이동 (REQ-AUTH-006)

#### SCR-054 회원 탈퇴
1. 안내: 삭제되는 정보와 일정 처리 방식 (REQ-AUTH-009)
2. 비밀번호 확인: 본인 확인을 위해 현재 비밀번호 입력
3. 확인 체크: 체크해야 탈퇴하기 버튼 활성화
4. 탈퇴하기: 완료되면 "탈퇴가 완료됐어요" 안내 후 로그인(SCR-002)으로 이동
